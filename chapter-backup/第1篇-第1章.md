#### 1.1 大数据概念与特点

##### 1.1.1 大数据的判定标准

大数据场景的判定需要从多个维度综合评估，不能仅凭数据量级简单判断：

**数据规模维度：**
- **存储容量**：单机存储无法满足，需分布式存储（如 HDFS、S3、OSS）
- **计算资源**：单机 CPU/内存不足，需集群计算资源
- **网络带宽**：数据传输量大，对网络带宽要求高

**处理复杂度维度：**
- **实时性要求**：需要分钟级甚至秒级响应，传统批处理无法满足
- **数据多样性**：结构化、半结构化、非结构化数据并存，需统一处理
- **并发处理**：高并发读写，传统数据库锁机制成为瓶颈

**技术栈信号：**
- 必须引入分布式文件系统、分布式查询引擎
- 需要消息队列（如 Kafka、RabbitMQ）处理数据流
- 采用流式处理框架（如 Flink、Spark Streaming）进行实时计算
- 使用列式存储（如 Parquet、ORC）优化查询性能

**量化指标标准：**
- **数据新鲜度SLA**：T+0实时处理响应时间<1秒，T+1批处理窗口<4小时
- **质量门限值**：数据准确率>95%、完整性>99.9%、一致性>99.5%
- **成本效益ROI**：大数据投资回报率 = (收益增量 / 投资成本) × 100%，目标值>150%
- **性能基准**：查询响应时间<3秒，数据处理吞吐量>1000 TPS

**业务场景信号：**
- 用户行为分析、推荐系统、风控系统等需要处理海量用户数据
- IoT设备数据采集、日志分析等高频数据写入场景
- 实时监控、预警系统等对延迟敏感的业务场景

##### 1.1.2 5V 特性
1. **体量（Volume）**：数据规模从 TB 到 PB 甚至更大，单机难以承载。
2. **多样性（Variety）**：结构化、半结构化、非结构化数据并存。
3. **速度（Velocity）**：数据产生和处理速度快，要求实时/准实时响应。
4. **价值密度低（Value）**：有用信息比例低，需要高效挖掘。
5. **真实性（Veracity）**：数据中存在噪声、缺失、异常，需质量保障。

- **Variety**：结构化数据（订单表）占比30%，非结构化数据（用户评论、图片）占比70%

- **Value**：有效推荐数据占比仅8%，需通过算法挖掘潜在价值
- **Veracity**：数据缺失率2%，异常值占比3%，通过质量监控确保准确性

#### 1.2 大数据系统典型架构与组件

- 大数据系统是一条“数据价值流水线”，常见分层与质量关注点：
  - **数据源层**：业务库、日志、外部/第三方数据；关注采样代表性、接口契约、数据新鲜度。
  - **资源与调度层**：资源管理、作业编排、弹性伸缩；关注资源配额、抢占/优先级、失败重试策略、回滚与再平衡。
  - **数据服务层**：报表、API、特征服务、实时指标；关注接口契约、指标口径、缓存一致性、SLO 与回退策略。

  - **治理与安全层**：元数据、数据质量、血缘、安全与合规；关注口径治理、血缘闭环、审计、脱敏、访问控制与留痕。

**架构量化指标：**
- **数据新鲜度SLA**：数据源层新鲜度>99%，处理层延迟<5分钟，服务层响应<2秒
- **质量门限值**：端到端数据准确率>99.5%，血缘完整性>98%，审计覆盖率>100%
- **成本效益ROI**：系统投资回报期<2年，运维成本占总成本<30%
- **性能基准**：峰值处理能力>10,000 TPS，平均响应时间<1秒，可用性>99.9%

#### 1.3 测试数据管理与生成方法

- 传统测试：以功能、接口、单元测试为主，性能关注 QPS/响应时间、单机资源占用。
- 大数据测试：更关注数据质量、端到端对账、批/流作业吞吐与延迟、数据一致性/幂等性、资源利用率、基线与漂移、成本与弹性。
- 常用验证手段：
  - 统计性验证：分布、聚合、采样比对，避免逐条对账开销。
- **优点**：高度还原真实场景，覆盖复杂分布和异常模式。
- **常用方法**：
  - 随机采样：简单高效，但可能遗漏边界与罕见异常。
  - 分层采样：按业务维度/时间/地域/客群分层，提升代表性与稳定性。

  - 规则采样：定向提取高风险、高价值、异常或峰值场景。

**采样方法对比表**

| 方法 | 优点 | 缺点 | 适用场景 | 代表性 |
|---|---|---|---|---|
| 随机采样 | 简单高效，无偏 | 可能遗漏边界异常 | 大数据集快速验证 | 中等 |

| 规则采样 | 定向覆盖高风险场景 | 可能过度采样 | 异常模式识别 | 高 |

import psutil
import time
from datetime import datetime
import json
import requests

class SystemMonitor:
    def __init__(self, collection_interval=60):
        self.collection_interval = collection_interval
        self.metrics_history = []
        
    def collect_system_metrics(self):
        """采集系统级监控指标"""
        metrics = {
            "timestamp": datetime.now().isoformat(),
            "cpu": {
                "usage_percent": psutil.cpu_percent(interval=1),
                "count": psutil.cpu_count(),
                "load_average": psutil.getloadavg() if hasattr(psutil, 'getloadavg') else None
            },
            "memory": {
                "total_gb": round(psutil.virtual_memory().total / (1024**3), 2),
                "used_gb": round(psutil.virtual_memory().used / (1024**3), 2),
                "usage_percent": psutil.virtual_memory().percent,
                "available_gb": round(psutil.virtual_memory().available / (1024**3), 2)
            },
            "disk": {
                "total_gb": round(psutil.disk_usage('/').total / (1024**3), 2),
                "used_gb": round(psutil.disk_usage('/').used / (1024**3), 2),
                "usage_percent": psutil.disk_usage('/').percent,
                "free_gb": round(psutil.disk_usage('/').free / (1024**3), 2)
            },
            "network": {
                "bytes_sent": psutil.net_io_counters().bytes_sent,
                "bytes_recv": psutil.net_io_counters().bytes_recv,
                "packets_sent": psutil.net_io_counters().packets_sent,
                "packets_recv": psutil.net_io_counters().packets_recv
            }
        }
        return metrics
    
    def collect_application_metrics(self, process_name="spark"):
        """采集应用级监控指标"""
        app_metrics = {
            "timestamp": datetime.now().isoformat(),
            "application": process_name,
            "process_count": 0,
            "total_cpu_percent": 0,
            "total_memory_mb": 0,
            "processes": []
        }
        
        for proc in psutil.process_iter(['pid', 'name', 'cpu_percent', 'memory_info']):
            try:
                if process_name.lower() in proc.info['name'].lower():
                    proc_metrics = {
                        "pid": proc.info['pid'],
                        "name": proc.info['name'],
                        "cpu_percent": proc.info['cpu_percent'],
                        "memory_mb": round(proc.info['memory_info'].rss / (1024**2), 2)
                    }
                    app_metrics["processes"].append(proc_metrics)
                    app_metrics["process_count"] += 1
                    app_metrics["total_cpu_percent"] += proc.info['cpu_percent']
                    app_metrics["total_memory_mb"] += proc_metrics["memory_mb"]
            except (psutil.NoSuchProcess, psutil.AccessDenied):
                continue
                
        return app_metrics
    
    def send_to_monitoring_system(self, metrics, endpoint="http://monitoring.example.com/api/metrics"):
        """发送指标到监控系统"""
        try:
            response = requests.post(endpoint, 
                                   json=metrics, 
                                   headers={'Content-Type': 'application/json'},
                                   timeout=5)
            return response.status_code == 200
        except Exception as e:
            print(f"Failed to send metrics: {e}")
            return False
    
    def run_monitoring_loop(self):
        """运行监控循环"""
        print("Starting system monitoring...")
        while True:
            try:
                # 采集系统指标
                system_metrics = self.collect_system_metrics()
                
                # 采集应用指标
                app_metrics = self.collect_application_metrics()
                
                # 合并指标
                combined_metrics = {
                    "system": system_metrics,
                    "application": app_metrics
                }
                
                # 发送到监控系统
                success = self.send_to_monitoring_system(combined_metrics)
                if success:
                    print(f"Metrics collected and sent at {system_metrics['timestamp']}")
                else:
                    print("Failed to send metrics")
                
                # 存储历史数据（保留最近100个数据点）
                self.metrics_history.append(combined_metrics)
                if len(self.metrics_history) > 100:
                    self.metrics_history.pop(0)
                    
            except Exception as e:
                print(f"Monitoring error: {e}")
            
            time.sleep(self.collection_interval)

# 使用示例
if __name__ == "__main__":
    monitor = SystemMonitor(collection_interval=30)  # 30秒采集一次
    monitor.run_monitoring_loop()

```python
import pandas as pd
import numpy as np
from datetime import datetime, timedelta
import logging
import json

class DataQualityChecker:
    def __init__(self, data_source):
        self.data_source = data_source
        self.logger = logging.getLogger(__name__)
        self.quality_report = {
            "timestamp": None,
            "dataset": data_source,
            "checks": [],
            "overall_score": 0,
            "recommendations": []
        }
    
    def load_data(self, query=None):
        """加载数据进行质量检查"""
        try:
            if isinstance(self.data_source, str) and self.data_source.endswith('.csv'):
                self.df = pd.read_csv(self.data_source)
            elif isinstance(self.data_source, pd.DataFrame):
                self.df = self.data_source
            else:
                # 假设是数据库连接，这里简化处理
                self.df = pd.DataFrame()  # 实际实现中需要数据库连接
            return True
        except Exception as e:
            self.logger.error(f"Failed to load data: {e}")
            return False
    
    def check_completeness(self):
        """检查数据完整性"""
        total_rows = len(self.df)
        completeness_results = {}
        
        for column in self.df.columns:
            null_count = self.df[column].isnull().sum()
            completeness_rate = (total_rows - null_count) / total_rows
            completeness_results[column] = {
                "completeness_rate": round(completeness_rate, 4),
                "null_count": int(null_count),
                "status": "PASS" if completeness_rate >= 0.95 else "FAIL"
            }
        
        return {
            "check_type": "completeness",
            "results": completeness_results,
            "overall_completeness": round(np.mean([v["completeness_rate"] for v in completeness_results.values()]), 4)
        }
    
    def check_uniqueness(self):
        """检查数据唯一性"""
        uniqueness_results = {}
        
        for column in self.df.columns:
            unique_count = self.df[column].nunique()
            total_count = len(self.df)
            uniqueness_rate = unique_count / total_count
            uniqueness_results[column] = {
                "unique_count": unique_count,
                "uniqueness_rate": round(uniqueness_rate, 4),
                "duplicate_count": total_count - unique_count
            }
        
        return {
            "check_type": "uniqueness",
            "results": uniqueness_results
        }
    
    def check_consistency(self, rules=None):
        """检查数据一致性"""
        consistency_results = []
        
        # 示例规则：检查数值范围
        if rules is None:
            rules = {
                "amount": {"min": 0, "max": 1000000},
                "age": {"min": 0, "max": 150},
                "score": {"min": 0, "max": 100}
            }
        
        for column, rule in rules.items():
            if column in self.df.columns:
                min_val = rule.get("min")
                max_val = rule.get("max")
                if min_val is not None and max_val is not None:
                    invalid_count = ((self.df[column] < min_val) | (self.df[column] > max_val)).sum()
                    consistency_results.append({
                        "column": column,
                        "rule": f"range_{min_val}_{max_val}",
                        "invalid_count": int(invalid_count),
                        "valid_rate": round(1 - invalid_count / len(self.df), 4)
                    })
        
        return {
            "check_type": "consistency",
            "results": consistency_results
        }
    
    def check_accuracy(self, reference_data=None):
        """检查数据准确性（需要参考数据）"""
        accuracy_results = []
        
        if reference_data is not None:
            # 这里实现与参考数据的比对逻辑
            # 简化示例：检查数据类型一致性
            for column in self.df.columns:
                if column in reference_data.columns:
                    type_match = self.df[column].dtype == reference_data[column].dtype
                    accuracy_results.append({
                        "column": column,
                        "type_consistency": type_match,
                        "sample_values_match": True  # 简化检查
                    })
        
        return {
            "check_type": "accuracy",
            "results": accuracy_results
        }
    
    def generate_recommendations(self, check_results):
        """基于检查结果生成改进建议"""
        recommendations = []
        
        for check in check_results:
            if check["check_type"] == "completeness":
                for col, result in check["results"].items():
                    if result["status"] == "FAIL":
                        recommendations.append(f"数据完整性不足：{col}列缺失率过高({(1-result['completeness_rate'])*100:.1f}%)，建议补充数据源")
            
            elif check["check_type"] == "consistency":
                for result in check["results"]:
                    if result["valid_rate"] < 0.95:
                        recommendations.append(f"数据一致性问题：{result['column']}列{result['invalid_count']}个值超出合理范围")
        
        return recommendations
    
    def run_quality_checks(self):
        """运行完整的数据质量检查"""
        self.quality_report["timestamp"] = datetime.now().isoformat()
        
        if not self.load_data():
            return self.quality_report
        
        # 执行各项检查
        checks = [
            self.check_completeness(),
            self.check_uniqueness(),
            self.check_consistency(),
            self.check_accuracy()
        ]
        
        self.quality_report["checks"] = checks
        
        # 计算总体质量分数
        scores = []
        for check in checks:
            if check["check_type"] == "completeness":
                scores.append(check["overall_completeness"])
            elif check["check_type"] == "consistency":
                if check["results"]:
                    scores.append(np.mean([r["valid_rate"] for r in check["results"]]))
        
        self.quality_report["overall_score"] = round(np.mean(scores), 4) if scores else 0
        
        # 生成建议
        self.quality_report["recommendations"] = self.generate_recommendations(checks)
        
        return self.quality_report
    
    def export_report(self, output_path=None):
        """导出质量检查报告"""
        if output_path is None:
            output_path = f"data_quality_report_{datetime.now().strftime('%Y%m%d_%H%M%S')}.json"
        
        with open(output_path, 'w', encoding='utf-8') as f:
            json.dump(self.quality_report, f, ensure_ascii=False, indent=2)
        
        return output_path

##### 1.5.2 对架构与测试的影响

- 将环境监控与自动化告警纳入日常运维流程，及时发现和处理异常；关键链路设置 SLO 与错误预算。
- 定期组织环境巡检和应急演练（含跨地域切换、密钥/证书过期、配置漂移），提升故障恢复能力。
- 性能、成本、安全、合规等多目标需协同测试与监控。
- 自动化、智能化测试工具成为必备，人工巡检逐步减少。
- 测试需提前嵌入“契约/质量门/可观测性”设计，避免事后补救。
- 测试环境误用生产敏感数据，导致直接泄露或侧信道泄露。
- 脱敏不彻底或字段遗漏，存在反识别风险。
- 权限控制不严或账户共享，导致越权访问和审计缺失。
- 数据跨境/跨部门流转无审批与留痕，触发合规风险。

>

- 严格区分生产与测试环境，敏感数据只允许脱敏后流入测试；跨环境流转需审批。
- 建立分级脱敏标准和自动化流程，覆盖全字段并输出脱敏报告。
- 最小权限与时间限定访问，周期性权限复核与密钥轮换。
- 全链路留痕：数据流转、导入导出、访问日志、回放日志；接入 SIEM/审计平台。
- 对截图、导出文件、临时落盘路径设定保护策略和到期销毁策略。

##### 1.6.2 常见误区与注意事项

**误区1：数据量越大越好**
- 现实：盲目追求数据规模往往导致存储和处理成本激增
- 正确做法：基于业务价值评估数据收集的ROI，确保数据质量优先于数据量

**误区2：实时处理就是最好的**
- 现实：不是所有场景都需要毫秒级响应，过度实时化会增加系统复杂度
- 正确做法：根据业务SLA选择合适的处理时效，平衡成本和性能

**误区3：开源工具无所不能**
- 现实：开源工具需要专业团队维护和二次开发
- 正确做法：评估团队能力和维护成本，选择合适的商业/开源组合

**误区4：测试环境可以简化**
- 现实：测试环境与生产环境差异会导致测试结果不可靠
- 正确做法：尽可能模拟生产环境，包括数据量级、网络条件和并发压力
