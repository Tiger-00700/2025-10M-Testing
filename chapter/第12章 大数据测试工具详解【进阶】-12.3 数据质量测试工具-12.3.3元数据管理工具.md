#### 12.3.3 元数据管理工具

> 【阅读提示】本节聚焦：12.3.3 元数据管理工具。建议先看结构，再带着问题阅读，关注关键术语、流程与案例，结合自身项目做对照。

##### Apache Atlas

- **功能特点**：

  - 开源元数据管理和数据治理平台

  - 数据血缘跟踪

  - 分类和策略管理

  - 安全和访问控制

  - 与Hadoop生态集成

- **应用场景**：

  - 企业数据治理

  - 大数据资产目录

  - 数据流跟踪

  - 合规性管理

- **使用流程**：

  - 部署Atlas → 配置集成 → 创建分类体系 → 元数据导入 → 血缘分析

- **优势与限制**：

  - 优势：功能全面、生态集成、开源免费

  - 限制：部署复杂、资源需求高

##### Collibra

- **功能特点**：

  - 企业级数据治理平台

  - 集中式元数据管理

  - 数据目录和数据字典

  - 策略和规则管理

  - 工作流和协作功能

- **应用场景**：

  - 企业数据资产管理

  - 法规合规性管理

  - 数据质量监控

  - 业务术语管理

- **使用流程**：

  - 部署平台 → 定义业务术语 → 设置治理策略 → 执行数据映射 → 监控合规性

- **优势与限制**：

  - 优势：全面的治理功能、企业级支持、用户友好

  - 限制：付费软件、实施周期长

##### Informatica Enterprise Data Catalog

- **功能特点**：

  - 自动发现和分类

  - 智能数据血缘

  - 业务术语映射

  - 数据质量评估

  - 集成多种数据源

- **应用场景**：

  - 大规模元数据管理

  - 自动化数据发现

  - 数据治理项目

  - 数据资产目录建设

- **使用流程**：

  - 配置数据源连接 → 执行自动发现 → 手动标记和增强 → 生成报告

- **优势与限制**：

  - 优势：自动发现能力强、智能分析、企业级支持

  - 限制：付费软件、部署复杂

> 【章节重点难点总结】

- 要点：湖仓、流批一体、Serverless、数据治理、安全合规
- 难点：多云/混部环境的基准对齐与成本可视化
