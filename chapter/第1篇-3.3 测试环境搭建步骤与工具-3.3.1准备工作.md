#### 3.3.1 准备工作

> 【阅读提示】本节聚焦：3.3.1 准备工作 。建议先看结构，再带着问题阅读，关注关键术语、流程与案例，结合自身项目做对照。

搭建大数据测试环境前，需要完成一系列准备工作：

- **环境规划文档**：编写详细的环境规划文档，包括架构图、组件清单、配置参数等

- **硬件准备**：

  - 服务器：按照规划配置准备物理服务器或虚拟机

  - 存储设备：配置适当的存储系统，如NAS、SAN或本地存储

  - 网络设备：准备交换机、路由器等网络设备

- **操作系统安装**：

<a id="term-rhel"></a>
<a id="term-lts"></a>

  - 推荐选择：CentOS/RHEL 7.x/8.x或Ubuntu 18.04/20.04 [LTS](附录-术语与缩略语表.md#lts)

  - 安装基础包：开发工具、网络工具、存储工具等

  - 磁盘分区：合理规划磁盘分区，为HDFS等组件预留足够空间

- **基础配置**：

  - 系统参数调优：调整内核参数、文件句柄数等

  - 网络配置：设置静态IP、主机名、域名解析等

  - 防火墙设置：开放必要端口或配置适当的规则

  - SSH免密登录：配置节点间SSH无密码访问

- **依赖软件安装**：

<a id="term-jdk"></a>

  - [JDK](附录-术语与缩略语表.md#jdk)：安装Java 8或Java 11（根据组件要求）

  - Python：安装Python 3.x及必要的包

  - 其他依赖：根据需要安装其他基础软件
