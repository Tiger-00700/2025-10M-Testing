# 附录 参考文献

> 说明：本附录用于统一管理全书引用的参考文献。推荐采用以下两种风格之一，并在全书保持一致。
>
> - 数字编号风格（示例）：在正文中以 [1]、[2] 标注；在本附录以编号列出完整条目。
> - 作者-年份风格（示例）：在正文中以 (Smith, 2020) 标注；在本附录按作者字母序排列。

## 引用规范

- 所有关键定义、结论与数据均应有出处。
- 网络资源应包含访问日期；学术论文应包含 DOI；书籍应包含 ISBN。
- 若为开源项目文档，请标注项目名、版本与链接。

## 示例（数字编号）

1. Stonebraker, M. et al. The End of an Architectural Era (It’s Time for a Complete Rewrite). VLDB, 2007.
2. Armbrust, M. et al. Delta Lake: High-Performance ACID Table Storage over Cloud Object Stores. VLDB, 2020. DOI: 10.14778/3357377.3357380
3. Apache Hadoop. [https://hadoop.apache.org/](https://hadoop.apache.org/) (accessed 2025-11-03).

## 示例（作者-年份）

- Stonebraker, M. (2007). The End of an Architectural Era (It’s Time for a Complete Rewrite). VLDB.
- Armbrust, M. (2020). Delta Lake: High-Performance ACID Table Storage over Cloud Object Stores. VLDB. DOI: 10.14778/3357377.3357380
- Apache Hadoop (n.d.). [https://hadoop.apache.org/](https://hadoop.apache.org/) (accessed 2025-11-03).
