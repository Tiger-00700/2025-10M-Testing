# 安全巡检清单（Chapter 16 配套）

## 一、认证与授权
- 认证：启用MFA与短期凭据；服务账户定期轮转；凭据自动失效。
- 授权：RBAC/ABAC 最小权限；临时提权审批闭环；跨区域/多集群一致性。

## 二、脱敏与代币化
- 字段/表/管道级策略绑定；格式保持加密（FPE）、掩码、代币化；例外审批与记录。
- 日志与快照防泄露；回放/回滚中的一致性与可验证性。

## 三、审计与告警
- 访问/变更/导出事件完整记录；不可抵赖与签名；保留周期与版本档案。
- SIEM/SOAR 集成；异常检测规则与联动；处置演练与Runbook。

## 四、合规门与证据
- 驻留/跨境/目的限制/主体权利；策略即代码在CI阻断失败。
- 报告与证据输出到 tools/reports/ 并版本化；可回溯与审查。

## 五、CI 集成建议
- 在流水线插入 `tools/ci/security_patrol.py`，并根据环境参数设定检查项。
- 与政策检查（OPA等）、权限矩阵与审计管道对接，失败时阻断或降级发布。
