# 附录 术语与缩略语表
﻿# 附录：术语与缩略语表

| 术语/缩写 | 含义 | 备注/关联章节 |
| --- | --- | --- |
| DQ（Data Quality） | 数据质量（准确性、完整性、一致性、及时性等） | 第2篇、第9章 |
| SLA / SLO / SLI | 服务级别协议/目标/指标，用于量化可用性、延迟、错误率等 | 第3、4、18章 |
| CDC（Change Data Capture） | 变更数据捕获，常用于实时/增量采集 | 第6章 |
| ETL / ELT | 抽取-转换-加载 / 抽取-加载-转换 的数据处理模式 | 第8章 |
| Watermark | 流处理中的水位线，用于界定事件时间进度与迟到数据处理 | 第6、8章 |
| Checkpoint / Savepoint | 流作业状态快照/手工快照，支撑故障恢复与升级回放 | 第6、8章 |
| Time Travel | 表格式湖仓的时光回溯能力，支持版本查询/回滚 | 第3、7章 |
| 数据契约（Data Contract） | 对表/主题的 schema、约束、SLO 等的版本化约定 | 第14章 |
| Schema Registry | Schema/契约注册中心，提供兼容性校验与版本管理 | 第14章 |
| Lakehouse | 湖仓一体架构，融合数据湖与数仓能力 | 第3、7章 |
| IaC（Infrastructure as Code） | 基础设施即代码，以代码描述环境/配置，支持审计/回滚 | 第4、12章 |
| FinOps | 成本可观测与优化方法论，将成本指标纳入工程决策 | 第18、24章 |
| PII（Personally Identifiable Information） | 可识别个人信息，需脱敏/加密/最小权限管控 | 第10、13章 |
| RBAC / ABAC | 基于角色/属性的访问控制模型 | 第10章 |
| Observability（Logs/Metrics/Traces） | 可观测性三支柱：日志、指标、追踪 | 第18章 |
| Data Governance | 数据治理，含元数据、血缘、质量、权限、合规 | 第3、13章 |
| Drift | 质量/性能/模型漂移，需告警与回滚/再训练 | 第9、18、26章 |
| QoS / 配额 | 服务质量/资源配额，控制混部与优先级 | 第4、12、24章 |
> 说明：聚焦全书主线术语与指标，给出默认口径与首个出现章节。新增术语请补反例并对齐公式/数据来源，避免同词多义。

| SLO | 服务级别目标 | 关键信号阈值，如 P95 延迟、错误率 | 第1章 目标 |
| SLI | 服务级别指标 | 度量信号，支持趋势与基线对比 | 第1章 目标 |
| 数据契约 | Data Contract | YAML/JSON 描述 schema/质量/SLO/权限；版本化 | 第14章 |
| Schema 基线 | 结构基线 | 字段/类型/约束/分区的基线版本 | 第14章 |
| 语义层 | 口径层 | 维度/指标口径定义与生成 SQL | 第14章 |
| 血缘 | Lineage | 上下游依赖关系（字段/表/作业/指标） | 第14章 |

| 基线 | Baseline | 历史稳定区间（性能/质量/成本） | 第15/18/19章 |
| 对账一致率 | Reconciliation Rate | 1 - |差异行| / |对账行| | 第6/19章 |

| GitOps | Git 驱动运维 | 以 Git 记录与审查环境/配置变更 | 第12章 |

| 回放 | Replay | 用历史/合成数据重放链路，校验回归 | 第5/22章 |
| CLI Runner | 命令行运行器 | 统一入口执行用例/校验/回放 | 第15章 |
| 烟囱式用例 | Siloed Cases | 单链路、不可复用的用例形态 | 第15章 |
| 分层用例 | Layered Cases | 采/存/算/服/报 分层设计，可复用 | 第15章 |

> 使用建议：
> - 新增或修改术语时，同时更新正文首个出现位置的定义。
> - 所有公式需指明分母/分子与时间/窗口/粒度。
> - 若口径与默认不一致，请在正文显式标注差异与原因。
