## FIG-DQ-LOOP 数据质量闭环

```mermaid
flowchart LR
	A[源数据采集] --> B[数据探查 Profiling]
	B --> C[规则校验 Validation]
	C --> D{质量指标达标?}
	D -->|是| E[持续监控 Monitoring]
	D -->|否| F[问题定位 Diagnostics]
	F --> G[修复与补偿 Repair]
	G --> H[回归验证 Regression]
	H --> B
	E --> I[指标与趋势基线 Baseline]
	I --> B
```

## FIG-OBS-PIPE 可观测性数据管道

```mermaid
flowchart TB
	subgraph Collect[采集层]

		L[Log Shippers]
		T[Trace SDK / Agent]
	end

		A1[Aggregation]
		F1[Filtering]

		Q1[Query / Analytics]

	M --> A1
	L --> A1
	T --> A1
	A1 --> F1 --> E1 --> TS
	F1 --> LS
	F1 --> TR
	TS --> Q1 --> ML --> AL --> DG
	LS --> Q1
	TR --> Q1
```

```mermaid
	P[规划 Planning]\n需求/范围 --> G[生成 Generation]\n合成/抽样/克隆
```
