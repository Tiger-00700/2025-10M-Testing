````markdown
TDMS 文件相关示例（占位）。本目录提供一个轻量说明与一个小脚本，展示如何在没有真实 TDMS 库的情形下记录说明并进行 smoke 测试。

```bash
bash examples/10_tdms/preview_tdms.sh

powershell -File examples/10_tdms/preview_tdms.ps1
````
