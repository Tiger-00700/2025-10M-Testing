# 技术评估打分表（示例）

| 维度 | 权重 | 指标说明 | 评分(1-5) | 备注 |
|---|---:|---|---:|---|
| 价值与适配度 | 0.25 | 对业务/数据域的适配与收益预期 |  |  |
| 复杂度与维护性 | 0.15 | 学习成本、运维复杂度、升级与兼容 |  |  |
| 生态与兼容性 | 0.15 | 社区成熟度、与现有工具/平台的兼容 |  |  |
| 可观测与可验证性 | 0.15 | 指标输出、日志/追踪、报告固化能力 |  |  |
| 成本与风险 | 0.15 | 资源成本、迁移风险、锁定与退出策略 |  |  |
| 安全与合规 | 0.15 | 数据安全、访问控制、合规支持 |  |  |

总分 = Σ(评分 × 权重)。建议配合金丝雀试点与报告比对（tools/report_diff.py）。
