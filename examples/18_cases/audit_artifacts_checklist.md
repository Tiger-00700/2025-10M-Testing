# 数据治理与合规审计工件清单（模板）

使用方法：复制此清单到项目案例目录，按项打勾并附证据链接。

- [ ] 指标目录导出（最新，含血缘）
- [ ] 指标注册表（命名、口径、负责人、变更记录）
- [ ] 数据契约（JSON/YAML，字段/约束/版本/破坏性变更说明）
- [ ] 语义层模型（维度、度量、汇总口径）
- [ ] 质量规则与阈值（规则列表、失败处理策略）
- [ ] 掩码/脱敏策略（字段级策略与例外审批）
- [ ] 安全与访问控制（角色、策略、审计日志片段）
- [ ] 回放与对账证据（样本、差异报告、结论）
- [ ] 运行日志与告警（关键区段、SLA违约分析）
- [ ] 变更与发布记录（变更单、回滚预案、影响评估）
- [ ] 评审结论与签署（QA、治理、业务方）
